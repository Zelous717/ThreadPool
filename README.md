# ThreadPool (C++ 线程池)

这是一个基于 C++ 实现的简单线程池项目。用于多任务并发处理。

## 📋 功能特点
- 支持任务队列（Task Queue）
- 自动管理线程的生命周期
- (如果你有加锁，可以加上：) 使用互斥锁（Mutex）保证线程安全
- (如果你有什么独特功能，可以加在这里)

## 🛠️ 环境与编译
- **开发工具**：Visual Studio / VS Code (或者你用的其他工具)
- **编译语言**：C++ (比如 C++11 或 C++17)
- **编译方法**：
    1. 克隆仓库到本地。
    2. 打开项目文件。
    3. 编译并运行 `main.cpp`。

## 🚀 如何使用
(简单展示一下你的代码怎么调用，比如：)
```cpp
// 创建线程池，例如开启 4 个线程
ThreadPool pool(4);

// 提交任务
pool.enqueue([] {
    std::cout << "Hello from thread!" << std::endl;
});
